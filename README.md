# LaneDetection
Hệ thống phát hiện làn đường. 
Mục tiêu: Phát hiện các đường biên làn đường từ ảnh hoặc video giao thông. 
Chức năng chính: 
• Chọn vùng quan tâm. 
• Phát hiện cạnh. • Phát hiện đoạn thẳng. 
• Ước lượng làn đường bên trái và bên phải. 
• Hiển thị làn đường lên video.

# Cách chạy (tạm thời)
Chạy lệnh: python lane_detection.py input.mp4 output.mp4
(Cần có file tên input.mp4)
